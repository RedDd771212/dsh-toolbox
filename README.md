# 工具箱（dsh-toolbox）

一个通用的**工具 / 项目启动台**，做成 DeepSeek Harness 的面板插件：任何 exe 或网页都能登记成卡片，按分类分组、按扩展名路由、一键启动、随时关掉。

> **不预置任何工具**。工具是「这台机器上装了什么」的私事，所以装好就是空白清单，由你自己登记（先建分类，再把 exe 或网址填进分类）。这样它既可以是 FS mod 的工具箱，也可以是写代码 / 建模 / 音频的工具箱 —— 就是同一块面板换个分类而已。

- **一个面板切换项目（工作区）**，左边是目录树（目录 + 文件，点文件直接按扩展名打开）；
- **工具卡片点一下就启动**，不用每次翻文件夹找 exe；
- **工具按分类分组**：分类是设置里的一列实体（可以新建、改名、删除），面板顶上一排 chips 只看某一组；设置里也是「先选分类，再在这个分类里加工具」—— 工具多到上百个也不会翻半天；
- **按扩展名打开文件**：目录树里点一个 `.hks`，自动挑登记了该扩展名的工具（最长匹配优先，`.emevd.js` 压过 `.js`）；
- **随时关掉工具**：会「自动保存」的程序开着时，你改完文件它能把你改动盖回去 —— 面板里一键关，**手动开的那个也能关**（按 exe 名）；
- **网页快捷入口**：把常用站点也登记成一张卡片，点一下用默认浏览器打开；
- **右侧栏也能用**：右侧边栏的「开始」页里有一张「工具箱」卡片，开了就是一个迷你工具条，点一行就启动；
- **agent 也能用**：同一套能力做成了 agent 工具 `toolbox`，模型可以替你 `launch` / `stop` / `status`。

## 安装

插件是标准的 DSH bundle（`dsh.bundle.patch` + `dsh.client.platform = web`），没有构建步骤、没有运行时依赖。

```powershell
git clone https://github.com/RedDd771212/dsh-toolbox.git
```

然后在 DeepSeek Harness 里把它装进当前 profile：

```
plugin_manager install_bundle  target=<clone 下来的绝对路径>
```

装配完成后左侧栏会多一个「工具箱」图标，右侧边栏「开始」页多一张卡片。

## 怎么打开

两种入口：

1. 左侧栏的图标列表里多了 **工具箱**（一个鲸鱼 + 扳手的图标），点一下中央面板就切成它；
2. 右侧边栏 → **开始** 页 → 「工具箱」卡片，开了是一个紧凑的工具条（分类 chips + 一行一个工具 + 刷新），适合一边聊一边点。

第一次用先点右上角 **设置**，里面两页签：

- **项目**：点「+ 添加项目（选目录）」，弹系统目录选择框；
- **工具**：左边选分类（可新建 / 改名 / 删除），右边列这个分类下的工具；点一行展开改名字、分类、扩展名、exe、参数、备注。

配置存在 `%USERPROFILE%\.dsh\toolbox.json`，和 profile 无关，换 GUI 端口 / 换会话都还在。

## 分类怎么用

分类是一份独立清单（`categories: [{ id, name }]`），工具通过 `categoryId` 挂上去，所以：

- 改分类名字不会让工具掉出来；删分类时里面的工具不会跟着丢，会挪到剩下的第一个分类；
- 面板工具区会出现 `全部 / <分类> / …` 一排 chips，点一下就只显示那一类；
- 想开第二块业务不需要新插件：新建一个 `写代码`、`建模`、`音频` 分类，把对应工具加进去就行。

## 添加一个工具

设置 → 工具 → 选分类 → 「+ 添加工具」（或「+ 添加网站」）。一条工具包含：

| 字段 | 说明 |
| --- | --- |
| 名字 | 卡片上显示的名字 |
| 分类 | 挂在哪一组下 |
| 网站地址 | 填了就是网页条目（点击用默认浏览器打开），此时忽略 exe / 扩展名 |
| exe 路径 | 可执行文件的绝对路径 |
| 扩展名 | 逗号分隔、带点，例如 `.hks, .lua`，用于「点文件时该用谁」 |
| 参数 | 追加在文件参数之前的启动参数，支持引号 |
| 工作目录 | 留空 = exe 所在目录（带文件时 = 文件所在目录） |
| 可带文件 | 勾上才会把文件路径当最后一个参数传进去（纯 GUI 程序取消勾选） |
| 备注 | 给自己看的一句话 |

## 网页快捷入口

任何一条工具的「网站地址」填上就变成网页卡片（带 🌐），点一下用系统默认浏览器打开，不用管端口和路径。填了网址的条目会忽略 exe / 扩展名 / 「可带文件」。

## agent 工具

`toolbox`，常用：

| action | 说明 |
| --- | --- |
| `status` | 项目（工作区）、按分类分组的工具清单、正在运行的进程 |
| `launch` | `tool:"<工具名或 id>"`，可加 `file` / `cwd`；对网页条目就是用默认浏览器打开 |
| `stop` | `tool:"<工具名>"`，或 `name:"notepad++.exe"`（关掉手动开的），或 `pid:1234` |
| `tools` | 只看工具清单（分类 / 名字 / exe 或网址 / 扩展名） |
| `open_dir` | 在资源管理器里打开项目根目录 |

**改文件前先 `stop`**：这是这个工具最主要的用途 —— 很多编辑器 / 参数工具自己的自动保存比你的修改更「勤快」。

## 目录树怎么用

- 点目录名展开 / 收起，点**文件名** = 按扩展名挑工具直接打开；
- 文件行右边的「**⋯**」会列出所有工具，点哪个就用哪个打开；**扩展名对得上的会高亮**（那是自动路由会选的）；
- 顶部过滤框只过滤**已加载目录里的文件名**，不重新扫描磁盘 —— 工程目录里文件很多时用它缩小范围；
- 单层最多列 400 个目录 / 400 个文件，超出会提示「还有 N 个」，用过滤框缩小即可。

## 已知边界

- 工具进程是 `detached` 启动的：**宿主 / 面板重开不会把它们一起关掉**（这是故意的）；要关请用面板或 `toolbox`。
- 按名字关进程只在配置里登记过的 exe 上生效，防止误杀。
- 面板不会替你处理工具自己的「保存 / 不保存」对话框 —— 强杀时工具可能丢未保存状态。
- 目前只做了 `platform = web` 的 Client 半边（DSH Web / 桌面 GUI 通用），没有终端 UI。
